# 01 - 에이전트 협업 규칙 정의

Type: docs
Status: resolved
Depends on: None
Blocked by: None

## Question

메인 에이전트의 최종 책임을 유지하면서 서브에이전트에게 안전하고 효율적으로 작업을 위임하고, 결과를 검수·승인·재작업하기 위한 규칙은 무엇인가?

## Answer

`AGENTS.md`에 Agent collaboration 항목을 추가하고, 상세 규칙을 `docs/agents/collaboration.md`에 기록했다.

메인 에이전트가 사용자 의도, 범위, 위험, 최종 승인과 최종 응답에 책임을 지도록 했다. 서브에이전트에는 독립적이고 경계가 명확한 작업만 위임하며, 위임 정보와 결과 보고 형식을 정의했다. 메인 에이전트는 산출물과 검증 근거를 직접 확인한 뒤 승인하고, 실패 시 구체적인 피드백으로 재작업을 요청한다. 반복 실패, 병렬 충돌, 무단 범위 확장과 추가 권한이 필요한 조치에 대한 처리 기준도 포함했다.
