- 검수일: 2026-07-15
- 범위: 티켓 01~06 결정의 승인 MVP spec 통합, canonical domain/config/ADR 동기화, 구현 ownership과 acceptance gate
- 결과: Critical 없음. 세 검토 관점의 모든 High, Medium과 Low finding을 수정했고 2차 표적 재검토에서 잔여 finding 0을 확인했다.

## 검수 방식

메인 에이전트가 `.scratch/financial-terminal/spec.md`와 공유 정본만 편집했다. 읽기 전용 reviewer에게 architecture/security, spec quality/delivery, portfolio/trading 세 독립 관점을 배정했다. 1차 검토의 finding을 통합·수정한 뒤 같은 reviewer가 실패 항목만 표적 재검토했으며, 새 범위를 여는 finding은 허용하지 않았다.

1차 관점별 보고는 architecture/security High 7·Medium 5, spec quality/delivery High 8·Medium 2·Low 1, portfolio/trading High 7·Medium 6이었다. 겹치는 원인은 한 계약 수정으로 합쳤다. AccountChallengeDeliveryContext를 추가한 뒤 발견된 High 1과 OAuth 변수 Medium 1, 첫 표적 재검토에 남은 delivery High 2와 trading Medium 1도 같은 재작업 loop에서 해소했다.

## 해결한 계약

- SessionProof의 per-session generation과 account authorization epoch를 분리하고 current/all revoke, Workspace switch, CSRF와 federated identity assertion trust를 기계적으로 검증한다.
- email challenge의 pending/workspace target, request transaction, action material, session-less `pending | workspace` AccountChallengeDeliveryContext와 renderer/dispatch 수명주기를 고정했다.
- source resolver, Identity job/delivery resolver와 ProviderAuthorization의 canonical signature를 적고 raw getter, cross-purpose, stale Viewer Context 사용을 금지했다.
- AuthorizedTransport generation/fence, ProviderConnections mutation/revoke, AI consent/cache/provenance와 administrative erasure coordinator를 정본과 ADR에 동기화했다.
- Information Outcome, feed별 freshness와 upstream error matrix, synthetic-production 금지와 public/personal/local/free/deferred 범위를 acceptance oracle로 만들었다.
- TerminalView/PortfolioLoad revision·cancel·resume, Actual/Paper append-only 격리, Broker Snapshot/Sync lineage, PaperOrderIntent·simulation·external reducer를 구현 가능한 계약으로 고정했다.
- Web Push ingress/transport outcome, Resend quota·abuse·retry·bounce/complaint circuit, webhook/erasure tombstone와 unsubscribe/action-material 경계를 정확한 수치로 복원했다.
- cold/warm 성능 protocol, network-off CI, 여섯 opt-in contract flag, Mailpit pin, Docker/ZIP/문서/실데이터 screenshot 산출물을 release gate로 만들었다.
- 구현 lane F0~F11에 단일 owned scope, dependency, parallel group과 critical path를 지정했다.
