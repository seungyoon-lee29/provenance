# Evidence와 Provider Credential 격리

시장 정보와 뉴스·공시는 FinancialInformation이 Evidence로 정규화한다. ResearchAssistant에는 원문 묶음이나 client가 만든 raw Evidence·portfolio·order payload 대신 FinancialInformation, ActualPortfolio 또는 PaperTrading이 발급한 purpose-bound AI Material Reference만 전달한다. 각 source module의 server-only resolver가 Viewer Context, source ownership, AI Processing Consent와 표시·보존·외부 모델 처리·파생물 License Scope를 다시 확인하고 최소화된 AI Material Envelope를 만든다. 결과 provenance는 AI Material Reference와 그 자료가 인용한 Evidence Reference를 함께 보존한다. 데이터·AI·브로커 adapter는 Provider Credential을 직접 읽지 않고 ProviderConnections가 Viewer Context, 연결, 공급자, 환경, capability, credential generation/version, authorization fence, 허용 route와 만료에 묶어 발급한 AuthorizedTransport만 사용하며 임의 origin, 인증 header와 cross-origin redirect는 금지한다. rotate/revoke로 generation이나 fence가 바뀐 transport는 route call과 늦은 commit에 사용할 수 없다. 이 결정은 provider SDK를 직접 연결하는 구현보다 seam이 늘지만 source ownership, 사용자 권한, 콘텐츠 권리와 비밀 유출을 한 경계에서 막을 수 있다.
