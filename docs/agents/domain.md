# Domain Docs

이 프로젝트는 단일 컨텍스트 구조를 사용한다.

- 도메인 용어는 루트 `CONTEXT.md`에서 관리한다.
- 되돌리기 어렵고 중요한 결정은 `docs/adr/`에 기록한다.
- 설계·통합 작업은 `CONTEXT.md` 전체와 관련 ADR을 읽는다. 계약이 고정된 구현 작업은 직접 사용하는 용어와 관련 ADR을 최소 범위로 다시 확인한다.
- 문서가 없으면 조용히 진행하며, 용어나 결정이 실제로 확정될 때만 생성한다.
- 코드, 테스트, 티켓에서는 `CONTEXT.md`의 용어를 일관되게 사용한다.
- 기존 용어와 같은 의미의 새 이름을 만들지 않는다. interface나 저장 의미가 바뀌면 코드만 고치지 말고 같은 티켓에서 `CONTEXT.md`와 관련 ADR의 변경 필요성을 검토한다.
- `CONTEXT.md`가 커지면 별도 컨텍스트 파일로 분산하지 않고 제목과 `_Avoid_` 항목을 유지해 검색 가능하게 한다.
